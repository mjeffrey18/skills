# obsidian-project

Version 1

Create, resume and maintain a project in an Obsidian vault, from the first scoping to close-out or reopening. It keeps the project's documents in step as new notes and evidence arrive. It decides completion from evidence, never from an empty task list.

## When to use

- You start or continue a project that lives in your vault rather than in a code repository.

## Setup

- An Obsidian vault. The skill follows the vault's own `AGENTS.md` and folder conventions when it has them.

## Related skills

- [obsidian-create-idea](../obsidian-create-idea/README.md) for capturing ideas first.
