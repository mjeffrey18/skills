# Scoping conversation

Use for new projects or a materially changed scope. Reuse what the conversation and vault
already establish. Do not repeat settled discovery when resuming.

Ask one question at a time, recommend an answer where useful and explore related notes
before asking for information the vault can supply. Probe vague boundaries with a concrete
example. Stop when the outcome, scope, completion criteria and next actions are clear.

## Frame

Establish the project in one sentence, why it matters and what success looks like.
If the vault defines pillars, read the current list from the vault and recommend the relevant pillar.
Capture the mission, goals and purpose in IDEA.

## Scope

Identify what is in and out, requirements, hard constraints and how the result will be
checked. Capture these in IDEA, adding SPEC only when the detail warrants a separate file.
Mark unresolved choices as open rather than inventing agreement.

## Shape

Search for related projects, notes and meetings. Establish the broad route to completion,
dependencies and risks. Create PLAN if a phased sequence is useful, and TODO for the next
concrete actions. Record existing decisions and sourced findings in DECISIONS and FACTS.
Link sources through CONTEXT when a source index is useful. Keep raw capture in NOTES.

## Confirm material choices

Resolve the slug and target path. Summarise the proposed mission, scope, completion criteria
and approach. Ask for decisions that remain materially ambiguous. Existing explicit
instructions to create from an agreed brief are sufficient; do not demand another yes.

Create the core documents and only the supporting files with substantive content. Use
shared design guidance where relevant; create local guidance only when there is content.
