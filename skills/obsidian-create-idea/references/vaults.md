# Known vaults

Used only when `OBSIDIAN_VAULT_PATH` is unset and the user has not named a vault or path. Replace the example rows with your own vaults, one row per vault.

| Vault      | Domain                                   | Path                         |
| ---------- | ---------------------------------------- | ---------------------------- |
| `personal` | Your own ideas, home and personal tools  | `~/obsidian/personal/`       |
| `work`     | Work: product, engineering, team         | `~/obsidian/work/`           |

Each vault has `inbox/` and `action/6_INBOX.md`. `inbox/ideas/` may not exist yet - create it on first use.

When asking the user to choose, list every vault with a recommendation based on the idea's domain, and accept a bare path as an answer.
