# review-loop-claude

Version 1

Have Claude Code review your current change in a fix-and-re-review loop of up to three rounds, with you in the loop. You invoke it as `review-loop-claude [opus|fable] [target]`.

## Setup

- The Claude Code CLI, signed in with a Claude subscription.
- [review-loop-engine](../review-loop-engine/README.md), [review-critic](../review-critic/README.md) and [claude-code](../claude-code/README.md) (all required).
- Install it in harnesses other than Claude Code. A review by the same product adds little.
