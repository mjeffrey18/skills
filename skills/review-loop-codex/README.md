# review-loop-codex

Version 1

Have Codex review your current change in a fix-and-re-review loop of up to three rounds, with you in the loop. You invoke it as `review-loop-codex [sol|astra] [target]`.

## Setup

- The Codex CLI, signed in with ChatGPT.
- [review-loop-engine](../review-loop-engine/README.md), [review-critic](../review-critic/README.md) and [codex](../codex/README.md) (all required).
- Install it in harnesses other than Codex.
