# git-kiss

Version 1

A reference for [git-kiss](https://github.com/mjeffrey18/git-kiss) (`gk`), a small CLI for rebase-based git workflows. It lets your agent start, rebase, squash and finish feature branches, manage worktrees and run deploy commands with the right `gk` command.

## When to use

- A project has a `.gitkiss.jsonc` file, or you use `gk` commands.
- You want short, safe commands for feature branches and worktrees.

## Setup

- Install git-kiss. See its [README](https://github.com/mjeffrey18/git-kiss).

See [Install](../../README.md#install) in the repository README. Install the related skills listed below as well.
