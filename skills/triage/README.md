# triage

Version 1

Walk through a list of items one decision at a time. Each question comes with context, options, pros and cons and a recommended answer, and uses your harness's interactive question tool. The skill learns from earlier answers, so similar items go faster. It ends with a decision log and changes nothing until you ask.

## When to use

- You have review findings, tickets, TODOs or recommendations, and want to settle each one with full context.

## Setup

- None. It works best in a harness with an interactive question tool, such as `AskUserQuestion` in Claude Code. Otherwise it falls back to a fixed text format.
